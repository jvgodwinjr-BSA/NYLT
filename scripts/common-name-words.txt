# Words that are ordinary English AND also common given names or surnames.

# The name guard will not flag these on their own — only as part of a full-name
# phrase ("Jane Fields" is caught, the word "fields" is not). Without this list a
# roster containing a surname like Lane produces dozens of false positives, because
# "lane" is this app's core concept. A guard that cries wolf is a guard you turn off.
#
# This list is GENERIC and safe to commit: it is not derived from any roster, so it
# reveals nothing about who is on one. Per-roster additions belong in the gitignored
# scripts/scrub.local.txt, where a line starting with '-' allows one more word.
#
# Deliberately NOT here: given names whose name reading dominates in ordinary prose —
# seasons, months, virtue names, times of day. Those stay flagged on their own, which is
# what you want: the one name that ever reached this repo's git history was of that kind.
# (This comment describes the criterion rather than listing examples, because listing them
# would name people on the roster — the guard rejects this file if it does.)
